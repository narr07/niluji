# Catatan Perubahan NILUJI Siswa

## v0.1.0 (2026-11-19)

Rilis pertama aplikasi Android untuk siswa.

- Menyambung ke server NILUJI lewat pindai QR kartu peserta atau alamat yang diketik.
- Memastikan alamat adalah server NILUJI di jaringan lokal sebelum membuka portal ujian.
- Selama ujian hanya halaman dari server yang dipilih yang boleh dibuka.
- Mode ujian Android: blokir tangkapan layar, layar tetap menyala, penyematan aplikasi, dan konfirmasi tombol kembali.
