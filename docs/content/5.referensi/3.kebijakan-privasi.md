Berlaku untuk aplikasi Android **NILUJI Siswa** (`com.narr07.niluji.siswa`). Terakhir diperbarui 19 November 2026.

## Ringkasan

NILUJI Siswa adalah aplikasi untuk mengikuti ujian sekolah di jaringan lokal. Aplikasi ini **tidak mengirim data apa pun kepada pengembang**, tidak memuat iklan, tidak memakai analitik, dan tidak membagikan data kepada pihak ketiga.

## Data yang dipakai aplikasi

| Data | Untuk apa | Disimpan di mana |
| :--- | :--- | :--- |
| **Kamera** | Memindai QR pada kartu peserta untuk mendapatkan alamat server ujian. | Gambar kamera hanya diproses di HP dan tidak disimpan maupun dikirim. |
| **Alamat server terakhir** (misalnya `192.168.1.10`) | Mempercepat masuk pada ujian berikutnya. | Hanya di HP. Terhapus bila data aplikasi dihapus. |
| **Data ujian**: NISN, nama, token ujian, PIN kartu peserta, dan jawaban | Mengikuti ujian. | Dikirim ke **server ujian milik sekolah** di jaringan lokal, yaitu komputer pengawas yang menjalankan NILUJI Desktop. Tidak dikirim ke pengembang. |

Data ujian dikelola oleh sekolah yang menjalankan server ujian. Untuk melihat, memperbaiki, atau menghapus data ujian, hubungi guru atau pengawas di sekolah.

## Yang tidak dilakukan aplikasi

- Tidak mengumpulkan lokasi, kontak, foto, berkas, atau ID iklan.
- Tidak memuat iklan dan tidak memakai SDK analitik atau pelacakan.
- Tidak membuka situs di luar server ujian yang dipilih siswa.
- Tidak mengirim data ke internet. Koneksi hanya ke alamat jaringan lokal.

## Keamanan

Portal ujian memakai HTTP di jaringan lokal sekolah, bukan HTTPS. Sekolah disarankan memakai WiFi ujian yang dilindungi password. Selama ujian, aplikasi memblokir tangkapan layar dan rekam layar.

## Anak-anak

Aplikasi ini dipakai siswa sekolah, termasuk anak di bawah 13 tahun, di bawah pengawasan guru. Karena aplikasi tidak mengumpulkan data untuk pengembang, tidak ada data anak yang diterima, disimpan, atau dibagikan oleh pengembang.
