**NILUJI** hanya perlu diinstal pada **1 komputer pengawas/guru (PC Proktor)**. Perangkat siswa (HP Android, iPhone, tablet, Chromebook, atau laptop) **tidak perlu menginstal aplikasi apa pun** karena siswa cukup mengakses halaman ujian melalui browser bawaan (Chrome, Safari, Edge, atau Firefox).

## Kebutuhan Sistem Minimum

| Perangkat | Spesifikasi Minimum | Rekomendasi Ruang Ujian |
| :--- | :--- | :--- |
| **PC Proktor (Server)** | Windows 10/11 (64-bit), Ubuntu 22.04+, atau macOS 12+; RAM 4 GB; Ruang kosong 200 MB | RAM 8 GB; terhubung ke router WiFi menggunakan kabel LAN (Ethernet) agar koneksi paling stabil |
| **Router WiFi Lokal** | Hotspot laptop / Router WiFi standar (2.4 GHz) untuk <= 25 siswa | Router Dual-Band (2.4 GHz & 5 GHz) atau Access Point kelas untuk 30 sampai 120 siswa serentak |
| **Perangkat Siswa** | HP/Tablet/Laptop dengan browser modern dan WiFi aktif | Baterai minimal 50% sebelum sesi ujian dimulai |

## Mengunduh Installer Resmi

Unduh berkas pemasang (*installer*) sesuai sistem operasi komputer pengawas melalui halaman **[Rilis & Unduhan](/rilis)** atau langsung dari [GitHub Releases](https://github.com/narr07/niluji/releases/latest):

::tabs
  :::tabs-item{label="Windows (.exe / .msi)" icon="i-lucide-monitor"}
  1. Unduh berkas `Niluji_x.y.z_x64-setup.exe` (disarankan) atau `Niluji_x.y.z_x64_en-US.msi`.
  2. Klik dua kali berkas yang diunduh. Jika muncul jendela *Windows SmartScreen*, klik **More info** lalu pilih **Run anyway**.
  3. Ikuti panduan instalasi hingga selesai, lalu buka **Niluji** dari menu Start atau pintasan Desktop.
  4. Saat pertama kali dibuka, jika muncul jendela *Windows Defender Firewall*, centang **Private networks** dan **Public networks**, lalu klik **Allow access** agar HP siswa dapat mengakses server ujian.
  :::

  :::tabs-item{label="Linux (.deb / .AppImage)" icon="i-lucide-terminal"}
  1. Untuk distribusi berbasis Debian/Ubuntu/Mint, unduh berkas `niluji_x.y.z_amd64.deb` lalu pasang lewat terminal:
     ```bash
     sudo apt install ./niluji_*_amd64.deb
     ```
  2. Untuk distribusi Linux lainnya, unduh berkas `.AppImage`, berikan izin eksekusi, lalu jalankan:
     ```bash
     chmod +x niluji_*.AppImage
     ./niluji_*.AppImage
     ```
  :::

  :::tabs-item{label="macOS (.dmg)" icon="i-lucide-laptop"}
  1. Pilih `Niluji_x.y.z_aarch64.dmg` untuk Mac dengan chip Apple Silicon (M1/M2/M3/M4) atau `Niluji_x.y.z_x64.dmg` untuk Mac berbasis Intel.
  2. Buka berkas `.dmg` dan seret ikon **Niluji** ke dalam folder **Applications**.
  3. Jika macOS menampilkan peringatan aplikasi belum ditandatangani Apple Developer, jalankan perintah berikut satu kali di Terminal sebelum membuka aplikasi:
     ```bash
     xattr -cr /Applications/Niluji.app
     ```
  :::
::

## Lokasi Penyimpanan Database & Berkas Gambar

Seluruh data sekolah, daftar siswa, bank soal, gambar soal, dan hasil ujian disimpan secara lokal di komputer pengawas pada direktori data aplikasi (`com.narr07.niluji`):

- **Windows**: `C:\Users\<NamaUser>\AppData\Roaming\com.narr07.niluji\`
- **Linux**: `~/.local/share/com.narr07.niluji/`
- **macOS**: `~/Library/Application Support/com.narr07.niluji/`

Di dalam folder tersebut terdapat:
- `cbt.sqlite` : Berkas utama database SQLite.
- `uploads/` : Folder seluruh gambar pertanyaan dan gambar opsi jawaban.
- `backups/` : Folder tempat 14 salinan cadangan otomatis (`cbt-backup-YYYYMMDD-HHMMSS.sqlite`) disimpan setiap kali aplikasi dibuka.

::note
**Aman Saat Upgrade Versi**: Ketika Anda memasang versi baru NILUJI di atas versi lama, database `cbt.sqlite` dan folder `uploads/` tidak akan terhapus. Bahkan jika Anda memperbarui dari instalasi versi awal yang masih memakai folder `com.nicolaspadari.nuxtor`, NILUJI otomatis memigrasikan seluruh database dan gambar Anda saat pertama kali dijalankan.
::
